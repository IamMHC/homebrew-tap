# homebrew-tap

Homebrew tap for [mac-tiling-setup](https://github.com/IamMHC/mac-tiling-setup) —
a keyboard-driven tiling desktop for macOS.

```bash
brew install iammhc/tap/mac-tiling-setup
mac-tiling-setup
```

The first command installs the tools. The second writes the configs, backing up
anything already there.
